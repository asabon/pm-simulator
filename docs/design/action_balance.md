# ⚖️ キックオフ アクションバランス ＆ トレードオフ一覧 (Action Balance)

## 1. 設計思想
ノーリスクで選べてしまう固定正解コマンドをなくし、すべての事前調整アクションに**「得られるメリット (🟢緑)」**と**「代償・リスク・副作用 (🔴赤)」**を設定。所有 3 AP をどのカテゴリに分配するかで明確な戦術（ビルド）が生まれるように設計。

## 3. 順序コンボ（シナジー効果 ＆ 実行順序の重要性）
同じアクションの組み合わせであっても、**「何を先に実行したか（事前根拠があるか）」という実行順序**によってステークホルダーのリアクション、評価ボーナス、およびコンボの発動有無が変化します。

* **【王道の順番】現場リスク精査 ➔ 段階リリース提案**:
  - 先に現場で実工数を精査してから提案するため、顧客の不満が抑えられ `🌟 【順序コンボ】根拠ある事前交渉` が発動！
  - *(※無根拠にいきなり段階リリースを提案すると「不発」になり顧客満足度が低下)*
* **【共創の順番】要件定義WS ➔ 現場リスク精査**:
  - 顧客の求める仕様イメージを明確にしてから現場に落とし込むため `🌟 【順序コンボ】明確化からの現場着地` が発動し、PLの設計精度＆チーム士気が大爆発！
* **【筋を通す順番】上司納期直訴 ➔ 助っ人アサイン要請**:
  - 納期延長だけでは足りない根拠を示してから助っ人を要請するため `🌟 【順序コンボ】社内全面バックアップ` が発動！

## 4. 🧠 顧客非可視タイプモデル (3種) ＆ 動的応答ルール
案件生成時、顧客は以下の**3つの非可視（隠れ）アーキタイプ**のいずれかに設定されます。画面に直接表示はされず、Step 1 のセリフからプレイヤーがタイプをプロファイリング（推測）します。

| 隠れアーキタイプ | Step 1 ヒアリングの伏線セリフ | 🟢 反応が良いアクション (大成功) | 🔴 反応が悪いアクション (裏目) |
| :--- | :--- | :--- | :--- |
| **🤝 タイプA: こだわり伴走型** | `「現場が使いやすくてカッコいいデザインがいいな！画面を見ながら一緒に詰めていこうよ。」` | `💡 要件定義WS`<br>`📱 プロトタイプ提示`<br>💬「いいね！仕様を詰めるよ」 | `👥 段階リリース提案`<br>💬「全部こだわりたいのに機能を削るのか…？」 |
| **💼 タイプB: 完全丸投げ型** | `「細かい仕様？ それはプロの君たちが考えてよ。こっちは動くものが納品されれば文句ないからさ。」` | `🤝 QCD優先順位合意`<br>💬「結論だけ教えて。任せるよ」 | `💡 要件定義WS`<br>`📱 プロトタイプ提示`<br>💬「打ち合わせに時間取らせないでよ…」 |
| **⏱️ タイプC: 納期絶対型** | `「今回のリリース日は役員会で決定した絶対厳守だ。機能を削るのも納期延期も一切認めないよ。」` | `📱 プロトタイプ提示`<br>`🤝 QCD優先順位合意`<br>💬「事前にリスクを防げるならよし」 | `🏢 段階リリース提案`<br>`🏢 納期バッファ直訴`<br>💬「約束が違う！プロだろ！」 |

## 5. 🏢 上司信頼度 (`manager.trust`) 依存の動的応答分岐
PMの社内評価・実績値（上司信頼度: 0〜100）に応じ、`納期直訴` や `助っ人要請` を行った際のアクション応答が3段階に変化します。

* **🟢 信頼度高 (70〜100)**:
  - 💬 `「君がそこまで言うなら相当なリスクなんだな。よし、役員会を通してバッファを確保しよう！」` *(ペナルティ最小)*
* **🟡 信頼度中 (40〜69)**:
  - 💬 `「理由をしっかり説明しろよ。次からは自力で何とかしろ。（上司信頼度-10%）」` *(標準ペナルティ)*
* **🔴 信頼度低 (0〜39)**:
  - 💬 `「また言い訳か？ 根拠もなく枠を広げられるわけないだろ！（直訴拒絶 or 評価大暴落）」` *(大激怒ペナルティ)*

Step 1 のヒアリング時、プレイヤーは**完全無料（ノーリスク）で以下の確認カードから最大2枚**を選択して深掘り確認できます。

| 確認カード名 | 対象 | 得られる隠れ情報 | Step 1 で確認した場合のメリット |
| :--- | :--- | :--- | :--- |
| **❓ QCD優先軸の事前すり合わせ** | 👤 顧客 | 顧客タイプ看破 (こだわり/丸投げ/納期死守) | 💬「最初にそこを聞いてくれるとは流石だね！」<br>➔ **Step 2 での `QCD優先順位合意` の今さらペナルティを全消去** |
| **❓ 過去の類似案件の失敗傾向** | 🛠️ PL | 現場の隠れ技術負債・リスクレベル看破 | 💬「そこを心配してくれたのはPMさんが初めてですよ！」<br>➔ **チーム安全度★ +1** |
| **❓ 上司のリスク容許範囲・懸念点** | 🏢 上司 | 上司の隠れ信頼度 ＆ 評価ライン看破 | 💬「最初から現実的なリスクを考えていて感心だな」<br>➔ **上司信頼度 +5%** |
