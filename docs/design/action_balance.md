## 3. 順序コンボ（シナジー効果 ＆ 実行順序の重要性）
同じアクションの組み合わせであっても、**「何を先に実行したか（事前根拠があるか）」という実行順序**によってステークホルダーのリアクション、評価ボーナス、およびコンボの発動有無が変化します。

* **【王道の順番】現場リスク精査 ➔ 段階リリース提案**:
  - 先に現場で実工数を精査してから提案するため、顧客の不満が抑えられ `🌟 【順序コンボ】根拠ある事前交渉` が発動！
  - *(※無根拠にいきなり段階リリースを提案すると「不発」になり顧客満足度が低下)*
* **【共創の順番】要件定義WS ➔ 現場リスク精査**:
  - 顧客の求める仕様イメージを明確にしてから現場に落とし込むため `🌟 【順序コンボ】明確化からの現場着地` が発動し、PLの設計精度＆チーム士気が大爆発！
* **【筋を通す順番】上司納期直訴 ➔ 助っ人アサイン要請**:
  - 納期延長だけでは足りない根拠を示してから助っ人を要請するため `🌟 【順序コンボ】社内全面バックアップ` が発動！
