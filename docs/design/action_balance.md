## 1. 設計思想
ノーリスクで選べてしまう固定正解コマンドをなくし、すべての事前調整アクションに**「得られるメリット (🟢緑)」**と**「代償・リスク・副作用 (🔴赤)」**を設定。所有 3 AP をどのカテゴリに分配するかで明確な戦術（ビルド）が生まれるように設計。

## 3. 順序コンボ（シナジー効果）
* **【王道の順番】現場リスク精査 ➔ 段階リリース提案**: 顧客のペナルティが相殺され納得度UP。
* **【共創の順番】要件定義WS ➔ 現場リスク精査**: PLの設計・見積もり精度大爆発。
* **【筋を通す順番】上司納期直訴 ➔ 助っ人アサイン**: 社内全面バックアップ獲得。
