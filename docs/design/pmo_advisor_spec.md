# 🦉 PMO（軍師・参謀）アドバイスシステム仕様 (PMO Advisor Spec)

## 1. 概要
PMO（Project Management Office / 事務局・ナレッジ担当）は、事業部直属の常設アドバイザーとしてプレイヤー（PM）に常時伴走し、状況に応じた助言、戦略的ヒント、および準備時間超過に対する警鐘（タイムリミットアラート）を提供するシステムです。

---

## 2. アドバイス生成・判定ロジック

`getPMOAdvice(projectState, kickoffHistory, currentDay)` 関数は、以下の優先順位に従ってダイナミックに助言文言を自動生成します。

### 判定優先度一覧

| 優先度 | 条件 | アドバイス種別 | セリフメッセージ例 |
| :---: | :--- | :--- | :--- |
| **1 (最優先)** | **キックオフ未完了 && Day 3 以降** | 🚨 タイムリミット警鐘 (準備オーバー) | `「PMさん！ キックオフ下準備に時間をかけすぎています！ すでにDay 3です。これ以上遅れると実開発期間が圧迫され納期遅延のリスクが高まります。そろそろキックオフを執り行いましょう！」` |
| **2** | **現場リスク精査済み && 段階リリース未実施** | 🌟 順序コンボ示唆 (根拠活用) | `「現場の工数・技術リスクの精査が完了しましたね！ 今なら現場の根拠を持って顧客に『段階リリース提案』を打診できますよ。」` |
| **3** | **キックオフ未完了 (Day 1〜2)** | 💡 下準備の案内 (セオリー) | `「キックオフ前ですね。まずは現場のPLと話して『技術リスク精査』を行うか、顧客フロアで『QCD優先軸のすり合わせ』を行うのがPMのセオリーですよ。」` |
| **4** | **下準備完了数 >= 2 && キックオフ未完了** | 🚀 決起推奨 | `「十分な下準備と根拠が整いましたね！ 開発チームフロアへ向かい『🚀 チームキックオフ決起』を執り行いましょう！」` |
| **5 (通常時)** | **キックオフ完了後 (スプリント中)** | 🛡️ スプリント伴走アドバイス | `「チーム体制が発足しました。開発陣の疲労度に注意しつつ、定期的な1on1やデモ提示で品質と満足度を維持しましょう。」` |

---

## 3. UI表示位置・描画
* メッセージボックスダイアログ枠上部、およびダッシュボードに **`🦉 PMOのアドバイス:`** のバッジ付きでリアルタイム描画されます。
