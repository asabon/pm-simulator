# 🚀 フェーズ1: キックオフ仕様 (Phase 1: Kickoff)

## 1. フェーズ概要
顧客・上司・現場の利害対立や案件の危険度（要件曖昧さ・無茶振り）を読み取り、有限な 3 AP を使って事前ネゴシエーション・防衛ラインを構築したうえで、デリバリー戦略を選択しチームで一致団結するフェーズ。

---

## 2. 4ステップ構成

1. **Step 1: 情報収集（無料ヒアリング）**
   - 上司、顧客、PLから無料で話を聞く。
   - 顧客の「QCD全盛り無茶振り」と現場の「不可能性・パンク」が判明。
2. **Step 2: PMの決断 ＆ ネゴシエーション (所有 AP: 3)**
   - 「対顧客」「対上司」「対現場」の全8アクションから AP 3 を使い事前調整。
   - 全アクションに🟢プラス効果と🔴トレードオフ/副作用が存在。
   - **実行順序（コンボ）が重要！**: 実行する順番によってステークホルダーのセリフリアクションや順序コンボ（シナジー効果/不発）が発動。
3. **Step 3: デリバリー戦略の宣言 (🌊 WF vs 🔄 アジャイル)**
   - 案件特性や事前ネゴの手応えに応じた推進方針を選択。
4. **🎉 Step 4: チームキックオフ決起 ＆ 防衛★診断**
   - 事前調整と戦略選択の成果を受け、PL・チームメンバーから熱い決起メッセージ。
   - 3大防衛指標（要件確定度/適応度、期待値ギャップ、チーム安全度）が★診断。
   - 「開発スプリント（第2フェーズ）へ突入！」ボタンで開発本編を開始。
