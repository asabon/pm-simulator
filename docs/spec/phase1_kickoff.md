# 🚀 フェーズ1: キックオフ仕様 (Phase 1: Kickoff)

## 1. フェーズ概要
顧客・上司・現場の利害対立や案件の危険度（要件曖昧さ・無茶振り）を読み取り、有限な 3 AP を使って事前ネゴシエーション・防衛ラインを構築したうえで、デリバリー戦略を選択しチームで一致団結するフェーズ。

---

## 2. 4ステップ構成

1. **Step 1: 情報収集（初期アセスメント ＆ 隠れプロファイリング）**
   - 上司、顧客、PLから基本ヒアリングに加え、**「初期確認カード（最大2枚選択・完全無料）」** で深掘り確認が可能。
   - **ウェルカム期のプロファイリング**: 最初（Step 1）で基本的な前提方針を確認すると好印象（大歓迎）で隠れ属性を完全看破できる。
2. **Step 2: PMの決断 ＆ 動的ネゴシエーション (所有 AP: 3)**
   - 「対顧客」「対上司」「対現場」の全8アクションから AP 3 を使い事前調整。
   - **動的レスポンス ＆ 後出しペナルティ判定**: 
     - **🔴 後出し大ペナルティ対象 (前提確認系)**: Step 1 で確認せずにスルーし、Step 2 で今さら確認・合意（`QCD優先度` 等）すると「今さら感」で満足度大暴落。
     - **🟢 後出し許容・正当相談対象 (精査提案系)**: 現場精査を経てからの `段階リリース提案` や `納期直訴` は「正当な状況変化・根拠ある相談」として高評価獲得。
     - **顧客タイプ ＆ 上司信頼度依存**: 顧客属性（3種）や上司信頼度（3段階）に応じ、納得度・セリフが分岐。
3. **Step 3: デリバリー戦略の宣言 (🌊 WF vs 🔄 アジャイル)**
   - 案件特性や事前ネゴの手応えに応じた推進方針を選択。
4. **🎉 Step 4: チームキックオフ決起 ＆ 防衛★診断**
   - 事前調整と戦略選択の成果を受け、PL・チームメンバーから熱い決起メッセージ。
   - 3大防衛指標（要件確定度/適応度、期待値ギャップ、チーム安全度）が★診断。
   - 「開発スプリント（第2フェーズ）へ突入！」ボタンで開発本編を開始。
