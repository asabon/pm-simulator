# 📊 フェーズ2: 開発スプリント仕様 (Phase 2: Sprint)

## 1. フェーズ概要
時間の自動進行（週進行）中、発生するイベント（定期報告・突発トラブル・仕様変更）に対し、適切な介入（AP消費による緊急対応・残業指示）を行い、安全かつ確実にプロジェクトを進行させるフェーズ。

---

## 2. コアループ
1. **時間経過・作業消化 (Weekly Progress)**:
   - メンバーのスキル・疲労度・開発手法（WF/アジャイル）補正に基づきタスク消化。
2. **割り込みイベント対応 (Alert & Directives)**:
   - バグ発生、顧客からの追加要望、メンバーの体調不良等に対し、指示を発行。
3. **定期報告・上司/顧客フォロー**:
   - 上司や顧客への状況報告（報告を怠ると信頼度が低下）。
