# 🎮 ProjectManager (PM) コマンド一覧仕様書

## 1. 概要
本仕様書は、プレイヤー（プロジェクトマネージャー）がゲーム内で実行可能な**意思決定コマンド**の体系、および `ProjectManager.getAvailableCommands(context)` により提供されるコマンド一覧の定義を定めます。

ゲーム内の意思決定はすべて `ProjectManager` クラスが Single Source of Truth (SSoT) としてコマンドメタデータを動的に生成し、UI（自席ダッシュボード）およびデバッグインスペクターに 100% 同期して提供されます。

---

## 2. コマンド設計原則
1. **リソース管理 (APシステム)**:
   - PMは毎朝 **3 AP (Action Points)** を保持（初期値）。
   - コストが 1 以上のコマンドを実行するたびに AP を消費し、残り AP が不足したコマンドは自動的に選択不可（disabled）となります。
   - 無料コマンド（Cost: 0 AP）は情報収集や対話など、ノーリスクで実行可能です。
2. **即時実行 vs アポ予約 (時間軸ダイナミクス)**:
   - **⚡ 即時実行**: 実行直後に効果・ダイアログ・ステータス変動が発生。
   - **📅 アポ予約**: 指定した日数後（例: 1日後、3日後）の予定表に会議をセットし、当日進行時に重要イベントとして発生。
3. **フェーズ連動 ＆ 条件分岐**:
   - キックオフ前（体制構築・事前調整フェーズ）とキックオフ後（開発本番・スプリントフェーズ）で実行可能なコマンドが自動的に切り替わります。

## 4. 今後の拡張予定（スプリント開発コマンド）
スプリント・開発本番フェーズの深化に伴い、以下のコマンドの追加が計画されています：
- `CODE_REVIEW_POLICY`: コードレビュー厳格化（品質向上 vs 進捗低下）
- `TEAM_BUILDING_EVENT`: チーム懇親会（疲労度大幅回復 vs 1日分の進行）
- `MIDTERM_DEMO`: 中間成果デモ会（顧客期待値調整）
