# PM Simulator v2 - ゲームデザイン・全体概要

## 🎯 ゲームコンセプト
プレイヤーがプロジェクトマネージャー（PM）となり、ステークホルダーや開発チーム、予算・納期・品質・信頼関係のバランスを取りながらプロジェクトの成功と自身のキャリアアップを目指すシミュレーションゲーム。

---

## 📌 コア体験・目指す面白さ
1. **「正解が一つではない」リアルな意思決定とジレンマ**
   - QCD（品質・コスト・納期）とステークホルダー・チームの満足度/信頼のトレードオフ
2. **直感的な操作性と状況把握**
   - 複雑すぎず、かつ深い戦略性を持つ意思決定体系
3. **リプレイ性とキャリアの成長**
   - プロジェクトごとの成否が次のプロジェクトや自身のキャリア・評価に波及するサイクル

---

## 🔄 コアループ（検討中）
1. **案件受託・状況把握・計画策定**
2. **実行フェーズ（日次/週次の意思決定・イベント・課題対応）**
3. **リリース・納品・評価精算**
4. **組織・キャリア更新（次の案件へ）**

---

## 📝 今後の検討事項
* プロジェクト進行の単位（日次ターン制 vs 週次スプリント制 vs リアルタイムなど）
* ステークホルダーおよびチームメンバーのパラメータ設計
* プレイヤーが取れるアクション（コマンド）の体系
* ランダムイベント・リスクの発生と対処メカニズム
